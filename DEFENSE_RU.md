# Подготовка к защите — Survey Corps Archive

По заданию защита даёт 30 баллов, live coding — ещё 20. Каждый участник должен понимать весь проект, включая чужие разделы.

## Краткая демонстрация

1. Открой главную страницу. Объясни выбор темы: фанатский архив с общим стилем Разведкорпуса. Покажи все пять пунктов навигации.
2. Найди в HTML `header`, `nav`, `main`, `section`, `article`, `aside` и `footer`. Объясни, что они описывают смысл частей страницы.
3. В `css/style.css` покажи `:root`. Изменение одной переменной меняет акцентный цвет во всём проекте.
4. Покажи Flexbox в шапке: `display: flex`, `align-items: center`, `justify-content: space-between`, `gap`.
5. Покажи Grid для трёх стен и галереи: `repeat(3, minmax(0, 1fr))` создаёт три равные колонки. `minmax(0, 1fr)` позволяет колонке сжаться, даже если внутри длинный текст.
6. Открой таблицу. `caption` объясняет её содержание, `th scope="col"` задаёт заголовки колонок, `th scope="row"` — строк. Обёртка `overflow-x: auto` позволяет прокручивать таблицу на телефоне.
7. В Episodes покажи Bootstrap: `row g-4`, `col-md-6`, `card h-100`. На экране от 768px две карточки стоят рядом, ниже — одна. Объясни, что Bootstrap подключён раньше авторского CSS, поэтому общие стили можно переопределить.
8. Измени ширину браузера. Пользовательские media queries находятся в конце CSS: 991px для планшетов и 640px для мобильного меню/компоновки.
9. Заполни форму вымышленными данными. Браузер проверяет `required`, `type="email"`, `minlength`; JavaScript дополнительно проверяет строки из пробелов. После успеха появляется карточка. Реальной отправки данных нет.
10. Открой досье и закрой Escape. Нативный `dialog` удерживает фокус, а обработчик `close` возвращает его кнопке, открывшей окно.

## Частые вопросы

**В чём отличие Flexbox от Grid?** Flexbox удобен для размещения элементов вдоль одной основной оси. Grid задаёт колонки и строки и удобен для сеток. Здесь Flexbox используется в навигации, Grid — для стен, персонажей и галереи.

**Почему `position: sticky`?** Боковая панель остаётся в видимой области при прокрутке, но ограничивается родительским контейнером. `top: 124px` оставляет место для шапки. На планшете и телефоне она возвращается к обычному потоку.

**Где absolute и relative?** `.hero` создаёт позиционированный контейнер, `.hero-art` заполняет его как абсолютное изображение. Затемнение — псевдоэлемент, текст остаётся обычным HTML.

**Что делает `:nth-child(even)`?** Выбирает чётных детей. У таблицы это чередующийся фон; у командиров — смена расположения фотографии на больших экранах.

**Как работает поиск?** Берётся текст запроса, приводится к нижнему регистру и сравнивается с текстом каждой строки через `includes()`. Неподходящие строки получают свойство `hidden`. Счётчик и сообщение обновляются отдельно.

**Почему `textContent`, а не `innerHTML`, для имени?** Введённое имя должно оставаться текстом. Оно не должно интерпретироваться как HTML.

**Почему `loading="lazy"`?** Неосновные изображения загружаются по мере приближения к экрану. Hero загружается сразу и имеет `fetchpriority="high"`.

**Что хранит форма?** Ничего постоянно. Данные находятся только в текущей странице. Создаётся файл через `Blob`, временный URL освобождается через `URL.revokeObjectURL`. Email и сообщение в карточку не попадают.

**Почему таблица относится к году 854?** У титанов меняются носители. Одна временная точка не позволяет случайно смешать данные разных частей сюжета.

## Практика live coding

- Поменяй золотой акцент через `--gold`.
- Сделай галерею двухколоночной на компьютере: измени число в `repeat()`.
- Добавь ещё один пункт во все пять шапок и объясни, почему статический HTML требует синхронного изменения страниц.
- Поменяй расстояние между карточками с `gap: 22px` на `gap: 30px`.
- Измени Bootstrap `col-md-6` на `col-lg-6` и проверь, на какой ширине появляются две колонки.
- Добавь обязательное поле в форму: `label`, уникальный `id`, `name`, `required`.
- Временно убери `overflow-x: auto` у таблицы, посмотри проблему на узком экране и восстанови правило.
- Добавь видимый `:focus-visible` новому интерактивному элементу и проверь клавишей Tab.

Перед сдачей внесите в README реальные имена и вклад участников и убедитесь, что каждый может объяснить эти изменения самостоятельно.
